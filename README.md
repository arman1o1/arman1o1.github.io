# arman1o1.github.io

Personal blog exploring artificial intelligence, machine learning systems, computational physics, cinema, and photography.

Live site: [https://arman1o1.github.io](https://arman1o1.github.io)

---

## Overview & Architecture

- **Zero Build Step**: Native HTML5, vanilla CSS (`assets/styles.css`), and lightweight client-side scripts.
- **Typography & Assets**: Responsive WebP images, self-hosted Inter & Playfair Display fonts, KaTeX for math rendering, and Prism.js for syntax highlighting.
- **Syndication**: Atom feed available at [`feed.xml`](https://arman1o1.github.io/feed.xml) and sitemap at [`sitemap.xml`](https://arman1o1.github.io/sitemap.xml).
