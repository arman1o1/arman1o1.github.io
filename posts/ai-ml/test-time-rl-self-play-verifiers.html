Test-Time Reinforcement Learning & Self-Play Verifiers: Scaling Reasoning Without Human Labels

November 26, 2026 • ☕ 12 min read

In Test-Time Compute & Reasoning Verification and Beyond Length-Biased RL, verifiable rewards depended on a human-curated dataset of ground-truth answers or unit tests. What happens when we run out of labeled reasoning problems – or face a brand-new problem distribution at deployment time? Three recent breakthroughs – Test-Time Reinforcement Learning (TTRL) (Zuo et al., NeurIPS 2025, arXiv:2504.16084), Absolute Zero Reasoner (AZR) (Zhao et al., 2025, arXiv:2505.03335), and Test-Time Self-Play (TTSP) (arXiv:2611.07367) – show how models can bootstrap their own rewards and curricula with zero human labels.

1. TTRL: Majority-Vote Pseudo-Labels as Online RL Rewards

Given an unlabeled test prompt $x$, TTRL rolls out $G$ trajectories $\{y_1, \dots, y_G\} \sim \pi_\theta(\cdot \mid x)$, extracts the final answer $\hat{a}_i$ from each, and computes the majority-vote consensus $y^* = \arg\max_a \sum_{i=1}^G \mathbb{I}[\hat{a}_i = a]$. Every rollout matching $y^*$ receives reward $r_i = 1$, and $\pi_\theta$ takes an online GRPO gradient step directly on the unlabeled test batch:

TTRL Self-Labeled Reward & AZR Minimax Learnability Curriculum
$$r_i^{\text{TTRL}} = \mathbb{I}\!\left[\hat{a}_i = \mathrm{mode}(\hat{a}_{1:G})\right], \qquad r_{\text{propose}}^{\text{AZR}}(\tau) = \begin{cases} 0 & \text{if } \bar{p}(\tau) \in \{0, 1\} \\ 1 - |2\bar{p}(\tau) - 1| & \text{otherwise} \end{cases}$$

2. Absolute Zero: Code-Executed Proposer–Solver Self-Play

Majority voting fails if the model is confidently wrong ($\mathrm{mode} \neq a_{\text{true}}$). Absolute Zero (AZR) replaces consensus with a deterministic Python sandbox as an incorruptible external oracle. One shared LLM plays two roles: a Proposer that invents new deduction/abduction/induction coding puzzles, and a Solver that solves them. The Proposer is rewarded most when the Solver's pass rate $\bar{p}(\tau)$ sits right at $50\%$ – automatically tracking the model's exact zone of proximal development with zero external datasets.

In Absolute Zero, the Python interpreter acts as the sole source of truth, allowing a single policy to co-evolve both difficulty curriculum and reasoning skill.
💻 Python: TTRL Majority-Vote Advantages & AZR Proposer Learnability RewardPyTorch 
import torch
from collections import Counter

def ttrl_majority_vote_advantages(extracted_answers: list[str]) -> torch.Tensor:
    """TTRL (Zuo et al., 2025): Majority-vote pseudo-label rewards + unbiased Dr. GRPO advantages."""
    consensus, _ = Counter(extracted_answers).most_common(1)[0]
    rewards = torch.tensor([1.0 if a == consensus else 0.0 for a in extracted_answers], dtype=torch.float32)
    # Subtract group mean without std division (Dr. GRPO) to avoid difficulty-bias amplification
    return rewards - rewards.mean()

def azr_proposer_learnability_reward(solver_pass_rate: float) -> float:
    """Absolute Zero (Zhao et al., 2025): Peak reward when task is right at the frontier (p = 0.5)."""
    if solver_pass_rate <= 0.0 or solver_pass_rate >= 1.0:
        return 0.0  # trivial (p=1) or impossible (p=0) tasks yield zero curriculum signal
    return 1.0 - abs(2.0 * solver_pass_rate - 1.0)
Self-Play Collapse Footguns: (1) Mode collapse in TTRL: without a KL penalty $\beta D_{\text{KL}}(\pi_\theta \| \pi_{\text{ref}})$ and entropy floor, majority-vote RL rapidly collapses onto a single short heuristic – even when wrong. (2) Proposer reward hacking: if the sandbox doesn't enforce deterministic execution and AST safety gates (no randomness, no trivial constant outputs), the Proposer will invent degenerate tasks that maximize $p = 0.5$ via coin flips.
