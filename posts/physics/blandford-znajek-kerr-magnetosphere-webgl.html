Extracting Energy from Gargantua: Force-Free Kerr Magnetospheres & Blandford–Znajek Relativistic Jets in WebGL2

In Spinning Up Gargantua: A Real-Time Kerr Black Hole in Your Browser, we integrated null geodesics in Boyer–Lindquist coordinates $(t, r, \theta, \phi)$ and visualized the ergosphere – the region between the outer event horizon $r_+ = M + \sqrt{M^2 - a^2}$ and the static limit $r_{\text{ergo}}(\theta) = M + \sqrt{M^2 - a^2\cos^2\theta}$ where spacetime frame dragging forces every physical observer to co-rotate with the black hole.

When a magnetized accretion disk threads poloidal magnetic flux $\Psi(r, \theta)$ across that spinning horizon, frame dragging twists the field lines azimuthally like a cosmic Faraday unipolar inductor. Discovered by Blandford & Znajek (1977) (Gralla & Jacobson, 2014, arXiv:1403.6959; Camilloni et al., 2023, arXiv:2310.20531), this electromagnetic torque extracts rotational energy directly from the Kerr black hole's irreducible spin reservoir, launching twin relativistic Poynting-flux jets observed in M87* and quasars.

0. Anatomy of a Force-Free Kerr Magnetosphere

Force-Free Condition
In a magnetically dominated corona ($\frac{B^2}{8\pi} \gg \rho_{\text{plasma}} c^2$), plasma inertia is negligible and the Lorentz force vanishes: $F_{\mu\nu}J^\nu = 0$, implying $\vec{E} \cdot \vec{B} = 0$.
Horizon Angular Speed
A Kerr black hole with spin parameter $a \in [0, M]$ rotates with horizon angular velocity $\Omega_H = \frac{a}{2 M r_+} = \frac{a}{r_+^2 + a^2}$.
Znajek Regularity
Requiring the electromagnetic fields to remain finite for an infalling observer crossing $r = r_+$ locks the poloidal current $I(\Psi)$ to the field-line angular velocity $\Omega_F$: $I(r_+, \theta) = 2\pi(\Omega_H - \Omega_F)\sin\theta\,\partial_\theta\Psi\,\frac{r_+^2 + a^2}{\Sigma_+}$.
Impedance Matching
Maximum electromagnetic power extraction occurs when the magnetosphere load matches the horizon membrane impedance at $\Omega_F = \frac{1}{2}\Omega_H$, giving $P_{\text{BZ}} \propto \Omega_F(\Omega_H - \Omega_F)B_H^2 r_+^4$.

1. The General-Relativistic Grad–Shafranov Stream Equation & Znajek Horizon Condition

For a stationary, axisymmetric force-free magnetosphere ($\partial_t = \partial_\phi = 0$), the electromagnetic 2-form $F = dA$ is completely determined by three flux-surface quantities: the poloidal magnetic flux $\Psi(r, \theta) = A_\phi$, the field-line angular velocity $\Omega_F(\Psi) = -dA_t / d\Psi$, and the poloidal electric current $I(\Psi)$:

Blandford–Znajek Poloidal Current & Outgoing Poynting Luminosity (Gralla & Jacobson, 2014)
$$I(\Psi) = \frac{2\pi (\Omega_H - \Omega_F)(r_+^2 + a^2)\sin\theta}{r_+^2 + a^2\cos^2\theta}\,\frac{\partial \Psi}{\partial \theta}\Bigg|_{r = r_+} \;\xrightarrow{\text{Split Monopole, } \Omega_F = \Omega_H/2}\; 2\pi \Omega_F (1 - \cos^2\theta)$$ $$P_{\text{BZ}} = \int T^r{}_t \sqrt{-g}\,d\theta\,d\phi = \int \Omega_F I(\Psi)\,d\Psi = \frac{\pi}{6} B_H^2 r_+^4 \Omega_H^2 + \mathcal{O}(a^4)$$

Notice the factor $\Omega_F(\Omega_H - \Omega_F)$: if $\Omega_F = 0$, the magnetic field lines are static and no Poynting flux $S^r \propto \Omega_F B_\phi$ flows outward; if $\Omega_F = \Omega_H$, the field lines co-rotate with the horizon and experience zero frame-dragging torque. The 50% slip $\Omega_F = \frac{1}{2}\Omega_H$ is an exact general-relativistic maximum-power transfer theorem!

// Evaluate force-free magnetic stream function Psi(r, theta) and toroidal pitch in Boyer-Lindquist coords
float evaluateKerrJetDensity(vec3 posBL, float spinA, float time) {
    float r = posBL.x, theta = posBL.y, phi = posBL.z;
    float rPlus  = 1.0 + sqrt(max(0.0, 1.0 - spinA * spinA));
    float omegaH = spinA / (2.0 * rPlus);
    float omegaF = 0.5 * omegaH; // Optimal Blandford-Znajek impedance matching

    // Parabolic collimated stream function Psi(r, theta) = r^p * (1 - |cos(theta)|)
    float cosT = abs(cos(theta));
    float psiFlux = pow(r / rPlus, 0.75) * (1.0 - cosT);

    // Frame-dragging azimuthal phase winding along flux tubes
    float helicalPhase = phi - omegaF * (r - rPlus) + omegaF * time;
    float tubeMod = 0.5 + 0.5 * cos(10.0 * helicalPhase);

    // Concentrate Poynting emission along the hollow parabolic jet sheath (Psi in [0.35, 1.15])
    float sheath = exp(-pow((psiFlux - 0.72) / 0.28, 2.0));
    return sheath * tubeMod * (omegaH * omegaH * 4.0);
}
