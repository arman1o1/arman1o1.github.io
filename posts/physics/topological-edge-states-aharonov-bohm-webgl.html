Topological Edge States & the Aharonov–Bohm Effect in WebGL2

November 26, 2026 • ☕ 11 min read

In Klein Tunneling & Zitterbewegung in Graphene, massless 2D Dirac fermions pierced electrostatic barriers head-on. Add a perpendicular magnetic flux $\Phi$ per lattice plaquette (or break time-reversal symmetry in a Chern insulator), and something even stranger happens: the interior bulk becomes an insulator, while the boundary hosts a one-way chiral superhighway protected by an integer topological invariant – the Chern number $C \in \mathbb{Z}$.

1. Peierls Substitution & the Aharonov–Bohm Plaquette Phase

Even if a magnetic field is confined strictly inside a solenoid where the electron never enters, the vector potential $\mathbf{A}$ imprints a measurable quantum phase $\Delta\phi = \frac{e}{\hbar}\oint \mathbf{A}\cdot d\mathbf{l} = 2\pi \Phi/\Phi_0$ around closed loops (the Aharonov–Bohm effect). On a discrete 2D square lattice in the Landau gauge $\mathbf{A} = (0, B x, 0)$, hopping along $y$ acquires a site-dependent Peierls phase:

Harper–Hofstadter Tight-Binding Hamiltonian & TKNN Chern Number
$$H = -t \sum_{x,y} \Big( c^\dagger_{x+1,y} c_{x,y} + e^{i 2\pi \alpha x}\, c^\dagger_{x,y+1} c_{x,y} + \text{h.c.} \Big), \qquad \alpha = \frac{\Phi}{\Phi_0}$$ $$C_n = \frac{1}{2\pi} \iint_{\text{BZ}} \Omega_n(\mathbf{k})\, d^2 k \in \mathbb{Z}, \qquad \Omega_n(\mathbf{k}) = i\big(\langle \partial_{k_x} u_n | \partial_{k_y} u_n \rangle - \text{c.c.}\big)$$

By the bulk-boundary correspondence, an interface between a $C = +1$ bulk and the $C = 0$ vacuum must host exactly $|C| = 1$ gapless chiral edge mode. Because there is literally no backward-propagating state at that energy on the same edge, an incoming wavepacket hitting a carved defect cannot reflect – it simply hugs the new boundary contour and continues unimpeded!

// Peierls-substituted tight-binding Hamiltonian step (Harper-Hofstadter lattice)
// Hopping along y picks up the Aharonov-Bohm phase exp(i * 2*pi * phi * x)
vec2 cMul(vec2 a, vec2 b) { return vec2(a.x*b.x - a.y*b.y, a.x*b.y + a.y*b.x); }

vec2 hPsi(ivec2 ij, float phi, float mass) {
    float phase = 6.2831853 * phi * float(ij.x);
    vec2 peierlsPlus  = vec2(cos(phase),  sin(phase));
    vec2 peierlsMinus = vec2(cos(phase), -sin(phase));
    vec2 pxP = texelFetch(uPsi, ij + ivec2( 1, 0), 0).rg;
    vec2 pxM = texelFetch(uPsi, ij + ivec2(-1, 0), 0).rg;
    vec2 pyP = cMul(peierlsPlus,  texelFetch(uPsi, ij + ivec2(0,  1), 0).rg);
    vec2 pyM = cMul(peierlsMinus, texelFetch(uPsi, ij + ivec2(0, -1), 0).rg);
    return -(pxP + pxM + pyP + pyM) + mass * texelFetch(uPsi, ij, 0).rg;
}
Unitary Time-Stepping on the Lattice: Just like our 2D Schrödinger Visscher leapfrog, explicit forward Euler $\psi^{n+1} = (1 - i\Delta t H)\psi^n$ has eigenvalues $|1 - i\Delta t E| \gt 1$ and explodes exponentially. Staggering $\operatorname{Re}(\psi)$ and $\operatorname{Im}(\psi)$ by $\Delta t / 2$ preserves the discrete norm $\sum_{x,y}|\psi_{x,y}|^2$ to machine precision for $\Delta t \lt 1 / \|H\|$ (and for complex Peierls phases, 4th-order Runge-Kutta preserves norm to $\mathcal{O}(\Delta t^6)$).
